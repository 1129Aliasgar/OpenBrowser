# Getting Started with OpenBrowser

OpenBrowser is a free AI coding agent and harness that allows you to use ChatGPT, Claude, or Gemini in your browser without API keys.

## Quick Start

1. Start the bridge server locally.
2. Install the browser extension.
3. Open ChatGPT or Claude in your browser.
4. Run prompts from your CLI.

Enjoy free AI-assisted coding directly in your workspace!
