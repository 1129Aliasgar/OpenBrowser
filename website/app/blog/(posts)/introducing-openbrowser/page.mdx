# Introducing OpenBrowser

The AI coding agent that runs locally without API keys.

## The Problem

Most AI coding assistants rely on cloud APIs, which means you have to pay for tokens and share your code with third parties.

## The Solution

OpenBrowser solves this by running completely locally.
